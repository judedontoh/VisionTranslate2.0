# ✧ VisionTranslate

### AI Vision • Live Translation • Real World

VisionTranslate is a free, browser-based camera translation application designed to help people understand the world around them.

## Features

- 📷 Live camera access
- 🤖 AI-powered object recognition
- 🌍 Multilingual object translation
- 📝 Text recognition using OCR
- 🔊 Voice pronunciation of translations
- ✨ Futuristic augmented-reality-inspired interface
- 📱 Responsive design for desktop and mobile

## Languages

Supported translation targets include:

- English
- Spanish
- French
- German
- Italian
- Portuguese
- Basque
- Japanese

## Technology

- HTML, CSS and JavaScript
- TensorFlow.js and COCO-SSD
- Tesseract.js OCR
- MyMemory Translation API
- Browser Speech Synthesis

## How to use

1. Open VisionTranslate in a modern browser.
2. Allow camera access.
3. Select your target language.
4. Start the scanner.
5. Scan objects or written text.
6. Listen to translated words using the speaker buttons.

## Requirements

An internet connection and camera permissions are required. Translation and recognition services may have availability and usage limitations.

## Project

VisionTranslate is an experimental project exploring accessible, real-time visual translation.

**Created with curiosity and a vision for a more connected world.**
